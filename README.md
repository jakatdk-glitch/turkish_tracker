# Türkçe Cepte — самоучитель турецкого 🇹🇷

**Turkish Tracker** — офлайн-приложение для самостоятельного изучения турецкого языка
с нуля до уровня A1–A2. Структурированный курс с теорией, практикой и тестами,
умное повторение слов, разговорник для поездки и раздел культуры. Полностью офлайн,
без аккаунтов и рекламы.

> Собрано на React Native + Expo (SDK 57). Целевая платформа — Android (локальный APK).
> Веб-версия работает как площадка для разработки и проверки.

## ✨ Возможности

### 📚 Курс (31 юнит, 5 модулей)
Путь юнитов открывается последовательно. Каждый юнит устроен одинаково:
**теория → практика → тест** (порог зачёта 70%, он открывает следующий юнит).

- **Теория** — короткие блоки: текст, таблицы суффиксов, примеры с озвучкой, подсказки-ловушки.
- **Практика** — очередь упражнений; неправильные возвращаются в конец очереди (как в Anki/Duolingo).
- **Тест** — 8 проверяемых заданий, при ≥70% юнит засчитывается (+30 XP).

**7 типов упражнений** (движок рендерит по JSON-описанию):
| Тип | Что делает |
|-----|-----------|
| `choice` | выбор перевода/формы из 4 вариантов (перемешаны) |
| `match` | сопоставление пар слово ↔ перевод |
| `flashcard` | карточка с переворотом и самооценкой (SM-2) |
| `blank` | впиши пропущенный суффикс (производство, а не узнавание) |
| `assemble` | собери предложение из слов (порядок слов SOV) |
| `morph` | собери слово из морфем — дистракторы ломают гармонию гласных |
| `listen` | *(зарезервировано)* аудирование |

### 🧪 Лаборатория слов (движок морфологии)
Изюминка приложения: живой конструктор турецкого слова — корень + мн. число +
притяжательность + падеж. Движок (`logic/morphology.ts`) детерминированно применяет
гармонию гласных на 2 и на 4, озвончение p/ç/t/k (kitap → kitabım), отвердение d→t
(iş → işte) и буферные буквы -y-/-s-/-n-, раскрашивает морфемы, объясняет чередования
и собирает живой русский перевод («kitabımızdan» → «из нашей книги»). Режим
«Проверь себя» — бесконечный тренажёр «собери слово» на том же движке.

**🔬 Рентген слова** — обратный ход движка (`logic/wordXray.ts`): любое слово
разрезается на морфемы с глоссами. Кандидаты разбора проверяются пересборкой через
те же правила, поэтому «гармонически невозможных» разборов не бывает; неоднозначные
слова (evinde, evleri) показываются честно, с альтернативным вариантом. Работает
всюду: тап по любому слову в сказках открывает разбор, а в лаборатории есть поле
для произвольного слова (в т.ч. имена собственные с апострофом: İstanbul’da).
Переводы корней берутся из лексикона, собранного из всего контента приложения.

### 🔁 Повторение (Spaced Repetition, SM-2)
Изученные слова возвращаются по умному расписанию — как раз перед тем, как забудешь.
Карточки в обе стороны (турецкий → перевод и перевод → турецкий) с независимым прогрессом.

### 💬 Разговорник
Две группы. **Туристу** — 94 фразы в 7 категориях (знакомство, кафе, магазин/торг,
транспорт, отель, экстренные ситуации, числа/время). **«Жизнь в Турции»** — разговорник
резидента, которого нет у массовых приложений: 80 фраз в 7 категориях (икамет и
миграция, аренда жилья, банк, почта/карго, у врача, госучреждения и нотариус,
коммуналка и связь) с бытовыми подсказками (aidat, depozito, yeminli tercüman…).
Поиск по турецкому и русскому, избранное ⭐, озвучка 🔊.

### 🧿 Культура
Живой язык — заходи в любой момент, без последовательности:
- **Пословицы** (40) — дословный перевод + смысл + русский аналог.
- **Скороговорки** (12) — с транскрипцией и тремя скоростями озвучки (🐢/🚶/🐇).
- **Традиции, обычаи, достопримечательности** (19 тем) — каждая заодно учит ключевым словам с озвучкой.

### 🎮 Геймификация и мотивация
Стрики 🔥, XP и уровни, достижения 🏆, heatmap-календарь активности, статистика точности
за 7 дней, «Пословица дня» на главной, локальные напоминания «не сломай стрик».

### 🔊 Озвучка (TTS)
Всё турецкое озвучивается через `expo-speech` с явным поиском турецкого голоса
(`tr-TR`). На телефоне работает из коробки, на десктопе — если установлен турецкий
голосовой пакет.

### 🎉 Отклик и анимации
- Анимированная карточка ответа + звук на правильный/неправильный (можно отключить в Профиле).
- Lottie-анимации в 5 «моментах»: онбординг, экран завершения, достижение, стрик, пустые состояния.
- Флип карточек и конфетти на reanimated.

### 👋 Онбординг
4 слайда при первом запуске (что за курс, как работают юниты, повторение, культура).

## 🎓 Программа курса

**Модуль 1 · Первые слова (A0)**
Алфавит и произношение → Приветствия → **Гармония гласных** → Знакомство (личные суффиксы) → Числа 0–100 → Вопрос `mı/mi` и `değil`

**Модуль 2 · Вокруг меня (A0+)**
Множественное число `-lar/-ler` → `Var/Yok` → Местный падеж `-da/-de` (+ отвердение) → Семья и притяжательность → Цвета и прилагательные → Дни недели и время

**Модуль 3 · Действия (A1)**
Настоящее время `-iyor` → **Отрицание и вопрос** → Винительный падеж (+ смягчение) → Куда/Откуда `-a/-e`, `-dan/-den` → Хочу и могу → В кафе → Прошедшее время `-di`

**Модуль 4 · Планы и мнения (A2)**
Аорист `-er/-ir` (привычки) → «У меня есть» (`arabam var`) → Будущее `-acak` (+ смягчение `k→ğ`) → Долженствование `-meli` → Сравнение `daha`/`en` → Послелоги `ile`/`için`

**Модуль 5 · Связная речь (A2+)**
Условие `-se/-sa` → `önce`/`sonra`/`kadar` → `-ken` (пока) → `-ince` (как только) → Порядковые числа и даты → Итоговый диалоговый юнит

> Порядок выстроен методически: гармония гласных — до первых суффиксов; отрицание и
> вопрос — сразу за настоящим временем («фразы выживания»). Грамматические правила
> (смягчение/отвердение согласных, буфер `-y-`) переиспользуются между темами, чтобы
> усваивались как система.

## 🚀 Запуск (разработка)

```bash
npm install
npx expo start          # затем: w — веб, или сборка на устройство
```

> ⚠️ **Expo Go не подойдёт**: проект на SDK 57, а публичный Expo Go отстаёт по версии.
> Для устройства собирается локальный APK (ниже). Веб (`w`) удобен для быстрой проверки
> UI; часть нативных функций (звук, уведомления, Lottie) на вебе работает частично или
> заменяется фолбэком.

Проверка типов:
```bash
npx tsc --noEmit
```

## 📦 Сборка APK (локально, Android)

Нативный проект уже сгенерирован (`android/`). После добавления нативных модулей
(`lottie-react-native`, `expo-audio`) перед сборкой нужно обновить нативный проект:

```bash
npx expo prebuild --platform android      # обновить android/ под новые модули
cd android
JAVA_HOME="<путь к JBR из Android Studio>" ./gradlew assembleRelease --no-daemon
```

Готовый файл: `android/app/build/outputs/apk/release/app-release.apk`

**Заметки для Windows:**
- `android/local.properties` должен указывать на Android SDK (`sdk.dir=...`).
- В цепочке C++-кодгена RN пути превышают 260 символов. Штатный `ninja` из
  `cmake/3.22.1` этого не умеет — он заменён на **ninja 1.12.1** (long-path-aware).
  Если SDK/cmake обновится, замену нужно повторить. `LongPathsEnabled=1` в реестре — включить.
- Java берётся из JBR, встроенного в Android Studio (`.../Android Studio/jbr`).

## 🎨 Ассеты (как заменить)

- **Lottie** (`assets/lottie/*.json`) — сейчас часть анимаций авторские/плейсхолдеры.
  Чтобы поставить свои: скачай Lottie JSON с [LottieFiles](https://lottiefiles.com),
  переименуй по таблице в `assets/lottie/README.md` и замени файл. Код менять не нужно.
- **Звуки** (`assets/audio/correct.wav`, `wrong.wav`) — сгенерированы синтезом. Можно
  заменить на свои WAV с теми же именами.

После замены нативных ассетов пересобери APK (`prebuild` не требуется, если новых
нативных модулей не добавлял).
